# YinYangYo Legacy Blog

Public-facing theme and documentation for a long-running Blogger technology archive (est. 2013).

- Official website: https://yinyangyohackers.blogspot.com/
- Platform: Google Blogger, not GitHub Pages or Vercel
- This public repository intentionally contains **no** posts export, unpublished drafts, API credentials, private contact data or private operations logs.
- The Blogger XML is a **staged candidate** built from an exported theme, **not verified as installed**. Back up the currently active theme, restore deleted legal pages, and use Blogger's Theme > Restore only after review.
- Original cover art files are in the private handoff until human review and platform upload.
- The AI Studio YYYH project is separate and not modified by this theme.
